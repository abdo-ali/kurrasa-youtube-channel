# الكُرّاسة | Kurrasa

Website for the Kurrasa kids YouTube channel (https://www.youtube.com/@kurrasa-kids), published with GitHub Pages:

- `index.html` — home page (also the home page of the channel's private YouTube management tool)
- `privacy.html` — privacy policy
- `terms.html` — terms of service

Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)` → https://abdo-ali.github.io/kurrasa-youtube-channel/
